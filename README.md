# 老友桌面 OldFriend Launcher

一款**开源免费**的 Android 适老化桌面（Launcher）：大字、大图标、大按钮，
**点家人头像 = 直接打微信视频/语音电话**，常用应用只放自己挑的那几个。

> 起因：市面上的「老人桌面」App 高级功能动辄收费，而核心体验其实不复杂。
> 于是用纯 Java + 原生 API（无第三方依赖、无 Gradle）自己实现了一个基本相同的开源版。

![icon](res/drawable-xxxhdpi/ic_launcher.png)

## 核心玩法

1. 添加联系人，填上**微信备注名**（微信里显示的那个名字）
2. 点这个联系人的大头像 → 自动：打开微信 → 搜索 TA → 进聊天 → 点「+」→ 点「视频/语音通话」

不用教老人找微信、翻通讯录、点菜单，一下到底。

## 功能

- **大字时钟卡**：时间 / 日期 / 星期 / 电量，字号自适应
- **联系人一键微信通话**：大头像 + 名字卡片，长按可改「视频/语音」、编辑、排序、删除
- **自选常用应用**：只放你要的几个（默认空，点「添加应用」勾选），不会把几十个应用全堆上去
- **语音播报**：点按播报名字、整点报时（系统 TTS）
- **桌面锁定**：锁定后长按不再弹菜单，防误删误改
- **6 套适老配色** + 字号 4 档 / 联系人每行 2·3 个 / 圆角 3 档
- **底栏三格**：联系人 / 应用 / 微信（设置藏在时间卡右上角齿轮，不占地方）
- **自动检查更新**：桌面打开后静默查一次 Gitee 最新版（12 小时最多一次），有新版本弹窗提示，
  点「去下载」打开 APK 直链；设置里可手动检查、可关掉自动检查
- 不联网、无广告、不上传任何数据

## 关于微信通话（无障碍服务）

微信没有公开的「发起通话」接口，所有「老人桌面」类 App 都是靠系统**无障碍服务**模拟点击实现的，本项目也一样：

- 服务名：**老友桌面微信通话**（设置 → 无障碍 → 已下载的服务里开启）
- 只读微信界面上的文字来找「搜索」「联系人名字」「+」「视频通话/语音通话」这几个控件
- 不读取聊天内容、不截图、不联网
- 微信大版本升级后控件文字可能变化，导致某一步找不到 → 会自动提示并回桌面，不会把老人卡在微信里

## 不做的功能

自动**接听**微信来电、远程协助/子女端、短信转发、跌落检测 —— 需要常驻后台与云账号，本项目不涉及。

## 构建

无需 Gradle、无需 Android Studio，只要 JDK + Android SDK 命令行工具：

```bash
bash build.sh   # aapt2 → javac → d8 → zipalign → apksigner，约 30 秒
```

产物：`OldFriendLauncher-v2.1.0.apk`（约 77 KB），支持 Android 4.4（API 19）~ Android 14+，v1+v2 签名。

## 项目结构

```
├── AndroidManifest.xml
├── build.sh                    # 无 Gradle 构建脚本
├── res/
│   ├── values/                 # 文案与主题
│   ├── xml/wx_service.xml      # 无障碍服务配置
│   └── drawable-*/ic_launcher.png
└── src/com/lcj/oldfriend/
    ├── LauncherActivity.java   # 主桌面（HOME）
    ├── WeChatService.java      # 微信通话无障碍自动化（状态机）
    ├── WxCaller.java           # 微信/无障碍入口与检测
    ├── SettingsActivity.java   # 设置
    ├── AppPickerDialog.java    # 选常用应用
    ├── ContactEditDialog.java  # 联系人编辑（微信备注名/通话方式）
    ├── TimeView.java           # 大字时钟卡（自绘）
    ├── AvatarView.java         # 圆形头像（自绘）
    ├── IconView.java           # 自绘矢量图标
    ├── Store.java / Contact.java / Prefs.java / Theme.java
    └── U.java / Tts.java / AppRepo.java / App.java
```

## 权限

只要一个：`READ_CONTACTS`（可选，用于"从手机通讯录找"）。不申请通话、定位、存储等权限。
